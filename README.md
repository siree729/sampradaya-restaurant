# Sri Sampradaya Family Restaurant & Banquet Hall

A modern, responsive, high-performance website for **Sri Sampradaya Family Restaurant and Banquet Hall**, located in Jagtial, Telangana.

## Features

- **Royal Menu Card Board**: Interactive, zoomable, high-resolution reader for the official restaurant menu card with full-screen lightbox viewing.
- **Atmosphere & Dining Cabins**: Highlighting family cabins, executive dining, and authentic cuisine.
- **Banquet Hall Showcase**: Dedicated section for event hosting, celebrations, conferences, and catering inquiries.
- **Contact & Location Details**: Interactive Google Maps integration, operating hours, and location guidance.
- **Responsive Design**: Optimized for all devices from mobile to 4K displays.

## Tech Stack

- **Framework**: React 18
- **Bundler & Dev Server**: Vite
- **Icons**: Lucide React
- **Styling**: Modern Vanilla CSS with responsive design system

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/siree729/sampradaya-restaurant.git

# Navigate to the project directory
cd sampradaya-restaurant

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
